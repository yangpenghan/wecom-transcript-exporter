    帮助与本地授权

    需要额外授权吗？

    无需注册企业接口，也不使用企业管理员令牌。请登录自己的企业微信账号。应用会请求本地读取授权，校验后的密钥由本机当前 Windows 账号加密保护。

    需要自己寻找数据库吗？

    自动查找会检查默认及重定向后的“文档”位置。找到多个账号时，请选择自己的账号。如更改过存储位置，可使用 在文件夹中查找、选择数据库文件，也可粘贴完整路径。

    读取失败怎么办？

    请确认企业微信与本应用在同一 Windows 账号下运行。正常重启企业微信后重试。客户端版本变化、权限级别不同或组织策略都可能阻止读取。应用不会提升权限或关闭防护；如受组织策略限制，请联系 IT。

    换一台电脑使用

    完整解压便携 ZIP，打开其中的程序即可，无需另装 Python。每个人都应连接自己的本地数据，并在自己的电脑上授权。分发程序时，请勿附带本地授权数据或导出的面聊记录。

    应用保存哪些数据？

    导出文件保存在你选择的文件夹中。偏好设置和加密密钥保存在 Windows 的 LocalAppData 文件夹。清除授权会移除已记住的同意记录及密钥，不会删除导出文件或企业微信数据。
