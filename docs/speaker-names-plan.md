# 本地成员姓名补全

目标：将原文中已有的企业微信成员 ID 精确对应到本机当前账号的通讯录姓名，保留已有姓名及逐字原文。用户已要求此能力；实现沿用本地 Python 服务和中文 HTML 界面。

实现边界：界面新增独立的“使用本地通讯录补全成员姓名”选项，默认不勾选。仅在导出时主动勾选才读取通讯录。CLI 使用 `--resolve-names`。不用云端接口，不上传通讯录，不按声音或文本猜测身份。

1. 用所选 `Profiles/<profile>/io_data.json` 中的 `user_info` protobuf 字段 1 定位同一 WXWork 根目录的 `<user-id>/Data/user.db`。不遍历其他账号，不支持时保留成员编号。
2. 联系人缓存使用独立的用户加密密钥目录；现有只读、当前用户和会话限定的密钥检查只增加 `user.db` 文件名白名单。
3. 只查询本次缺名成员的整数 ID。一个 ID 若出现冲突姓名则不替换；已有原始姓名和显式 CLI 映射优先。临时快照与联系人密钥纳入现有清理及撤销授权流程。
4. 合成测试覆盖账号定位、路径边界、ID 精度、冲突姓名、失败回退、未勾选不读取及已有姓名保持。用已授权的本地样例验证全部段落文字不变；私有姓名和数据只存放于忽略目录。
5. 完成浏览器流程验证、独立审阅和发布包隐私检查后发布 v1.3.0。公开仓库只包含合成样例与聚合验证结果。
