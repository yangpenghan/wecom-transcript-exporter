## 发现与处理

旧研发仓库的作者及提交者邮箱曾使用私人邮箱。其分支与标签已改为 GitHub noreply 地址，但旧提交缓存仍可能存在，因此旧仓库继续保持私有。本仓库独立创建，只复制经过审核的源码文件，不是 fork，不继承旧 Git 历史或对象。所有新提交均使用 GitHub noreply 地址。报告不重复列出原邮箱。作者名、GitHub 用户名及设计署名有意保留。

历史重写并不保证 GitHub 的旧提交缓存立刻消失。发布前需确认远端分支、标签及 Release 指向已清理的提交；若旧提交仍可通过原 SHA 读取，应继续保持私有，并通过 GitHub 支持渠道处理，或采用干净的新仓库发布。[GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)也区分历史重写与服务端缓存清理；支持团队是否受理取决于其敏感信息政策。
