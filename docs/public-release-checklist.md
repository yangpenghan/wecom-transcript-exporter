# 公开发布准备

已于 2026-10-19 经所有者确认公开发布，源码及 v1.2.0 便携包均可公开访问。

## 内容与隐私

- [x] 中文界面、中文首次使用指南、合成数据截图。
- [x] 数据库、密钥、导出原文、会话令牌、开发缓存均不进入版本库或便携包。
- [x] 检查历史版本、资源元数据和已有 v1.1.0 发布包。
- [x] 新建独立的干净历史，提交作者与提交者使用 GitHub noreply 地址。
- [x] 核查 v1.2.0 便携包的 68 个条目、校验和及发布内容。
- [x] 所有者选择 Apache 2.0；加入 LICENSE、NOTICE 并保留第三方声明。
- [x] 所有者确认后，将仓库可见性改为 Public，并验证旧研发仓库仍为私有。

本仓库从审核后的源码文件独立创建，不是 fork，也不继承旧研发仓库的 Git 对象、提交或标签。旧研发仓库保持私有；本次只公开了这个独立仓库。

## 分发边界

只分享 Releases 中的 ZIP。不要打包整个开发目录：本机保留的导出文件、历史备份、测试数据及授权状态仍可能包含隐私。

作者名、GitHub 用户名和设计署名是有意保留的公开信息。扫描采用规则检查与人工审阅，不能证明不存在任何未知类型的敏感信息。历史重写不会自动清除 GitHub 可能保留的旧提交缓存，也不会撤回别人已经取得的副本。

## 使用限制

支持 Windows x64，已验证的企业微信版本为 5.0.12.6018。程序未做数字签名；尚未在第二台实体 Windows 电脑上验证。组织策略和客户端升级可能影响读取。导出来源为本地缓存，不保证覆盖服务端全部记录。
