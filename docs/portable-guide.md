# Windows 便携版使用指南

1. 从项目 [Releases](https://github.com/yangpenghan/wecom-transcript-exporter/releases) 下载 Windows x64 ZIP，**完整解压**到本地文件夹。不要在压缩包内运行，也不要将程序与 `_internal` 文件夹分开。仓库为私有时，下载需要访问权限；直接收到 ZIP 则不需要 GitHub 账号。
2. 双击 **WeCom Transcript Exporter.exe**，浏览器会打开中文界面。无需安装 Python、Codex 或 WorkBuddy。
3. 打开企业微信并登录自己的账号，保持后台运行即可。导出不会占用鼠标或剪贴板。
4. 应用会检查默认及重定向后的“文档”位置。多个账号请自行选择；存储位置变更后，可使用**在文件夹中查找**、**选择数据库文件**或**手动输入位置**。支持的文件名为 `voice_room5.db`。
5. 阅读并勾选本地读取授权，点击**连接并显示面聊记录**。首次检查可能需要约一分钟，之后复用经过验证、由 Windows 加密保存的密钥。
6. 选择面聊记录和保存文件夹。如需将“成员 N”替换为真实姓名，勾选**使用本地通讯录补全成员姓名**，再点击**导出转录原文**。同时保存 Markdown 与 JSON，不覆盖已有文件。请查看完整性提示，再预览、下载或打开保存文件夹。
7. 完成后点击**退出应用**。仅关闭网页时，后台服务会在当前任务完成、约三分钟无活动后退出。

## 授权和数据

无需企业 API 注册、API 密钥或管理员令牌。应用不会代替你登录企业微信，不会向外部服务上传面聊数据。每个人都需要使用自己的账号，并能够访问相应记录。

首次连接会在征得同意后读取匹配的企业微信进程，取得并验证数据库密钥。密钥使用 Windows DPAPI 按当前用户加密，设置与密钥位于 `%LOCALAPPDATA%\WeComTranscriptExporter`。不要分享此文件夹。

临时解密快照在正常完成或处理错误后清理；强行结束进程后，下次启动会清理已退出进程的遗留快照。**帮助与授权 → 清除本地授权**移除同意记录及密钥，不删除企业微信数据和已导出的文档。

界面只监听本机 `127.0.0.1`，使用随机会话授权，脚本与字体均来自本地。其他电脑无法连接这个地址。

## 换电脑时的常见问题

姓名补全默认不勾选。勾选后只查询当前面聊里缺少姓名的成员 ID，使用所选账号对应的本地 `user.db`，不导出整份通讯录。首次可能需要另一次约一分钟的密钥检查。原文已有姓名优先；同一 ID 有冲突姓名、缺少本地账号信息或读取失败时保留成员编号。通讯录密钥独立加密保存，“清除本地授权”也会清除该密钥。

| 情况 | 处理方法 |
| --- | --- |
| 没有 Python | 便携包已包含运行环境，无需另装。 |
| 找不到数据库 | 登录企业微信，打开一条面聊并等待同步，再自动查找；迁移过存储位置则手动选择。 |
| 找到多个账号 | 根据显示的路径选择当前登录账号的数据。 |
| 列表为空或缺少记录 | 在企业微信打开目标记录，等待加载后刷新。 |
| 读取检查失败 | 确认同一 Windows 账号下正常运行，重启企业微信后重试。客户端更新可能需要适配；组织限制请联系 IT。 |
| 保存失败 | 选择可写入的本地 NTFS 文件夹，检查剩余空间。 |
| Windows 阻止运行 | 程序尚未数字签名。请从可信发布页获取；受组织策略限制请联系 IT，不要关闭防护。 |
| 浏览器没有打开 | 检查默认浏览器设置。浏览器启动失败时，程序会弹窗提供本地地址。 |
| macOS、Linux、ARM | 当前发布包仅支持 Windows x64。 |

应用不请求管理员权限，不修改持久系统策略。正常同用户访问在测试环境可行，但不能保证所有组织的策略允许读取。

## 完整性与兼容性

导出来源是**本地缓存**，并非服务端认证的完整历史。缺失消息编号、缺少录音结束标记、未知成员姓名及排除的非零状态记录都会提示；原文不做总结或去重。

已验证 Windows 企业微信 5.0.12.6018。客户端更新可能改变格式。便携版已进行迁移目录验证，尚未在第二台实体 Windows 电脑上验证。

**只分发 Releases 中的 ZIP。不要压缩整个工作目录**，其中可能包含私人导出、本地状态或开发备份。
